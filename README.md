📄 Resume Website

A responsive and clean **resume web page** built using **HTML and CSS**, designed to showcase my skills, education, and profile in a professional online format.

🔗 **Live Demo:** https://samriddhikhokhar.github.io/Resume/

---

🛠️ Tech Stack
- **HTML5** – Structure and content
- **CSS3** – Styling and layout
- **Flexbox** – Responsive alignment
- **Google Fonts** – Clean typography

---

 ✨ Features
- Fully responsive design (mobile & desktop friendly)
- Clean and minimal UI
- Professional resume layout
- Easy to customize and update
- Fast loading static website
